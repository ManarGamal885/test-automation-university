## About

The **Test Automation University** offers excellent courses to help developers, quality assurance engineers, and automation enthusiasts build their expertise in various testing frameworks, tools, and techniques.

This repository contains **hands-on practice exercises and optional implementations from specific TAU courses**, allowing you to reinforce knowledge gained throughout the tutorial videos and course instructions. You can clone this repository, navigate through different branches, and follow along with the exercises.

---

## Repository Structure

Each branch contains code specific to a particular course. You can switch to the relevant branch to access practice materials for that course.

### Branch: Selenium WebDriver

This branch contains practices and exercises for the **Selenium WebDriver** course offered by TAU.  
**Course Name**: [Selenium WebDriver with Java](https://testautomationu.applitools.com/selenium-webdriver-tutorial-java/chapter2.html)  
- **Focus**: Automating browser interactions using Selenium WebDriver with Java.
- Contains examples of:
  - Setting up WebDriver for different browsers.
  - Locating and interacting with elements on a web page.
  - Handling waits, assertions, and advanced WebDriver features.
  - Writing basic and advanced automated tests with Java.

## How to Use This Repository

1. Clone the repository to your local machine:
    ```bash
    git clone https://github.com/username/TAU-practice-repo.git
    ```

2. Switch to the branch you want to explore:
    ```bash
    git checkout selenium-webDriver
    ```

3. Open and explore the practice files related to the specific course:
   - Java source files (`.java`).
   - Configuration files (e.g., `pom.xml` for Maven dependencies).

4. Follow the course instructions and run the exercises using your favorite IDE (like IntelliJ IDEA or Eclipse).
